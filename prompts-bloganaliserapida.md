# Prompts — Blog Analise Rápida
> Nicho: Review de produtos físicos | Plataformas: Amazon BR + Mercado Livre  
> Objetivo: Tráfego orgânico → dúvida respondida → clique no link → comissão

---

## Prompt 1 — Review com intenção de compra

```
Escreva um artigo SEO em português brasileiro com o título 
"[PRODUTO]: Vale a Pena Comprar? Review Completo [ANO]".

Estrutura obrigatória:
- Introdução com a dúvida principal do comprador
- O que é o produto e para que serve
- Especificações técnicas em tabela
- Prós e contras reais
- Para quem é indicado / não indicado
- Onde comprar mais barato (Amazon BR e Mercado Livre)
- Veredicto final
- CTA claro com link de compra

Tom: especialista, honesto, sem exageros.
Palavra-chave no título, H2s e primeiro parágrafo.
```

---

## Prompt 2 — Artigo de dúvidas frequentes (FAQ)

```
Escreva um artigo respondendo as 7 perguntas mais comuns sobre [PRODUTO].
Formato: pergunta em H2 + resposta direta de 3 a 5 linhas.
Ao final de cada resposta, insira uma CTA natural para compra 
na Amazon BR ou Mercado Livre.
Otimizado para SEO e featured snippets do Google.
```

---

## Prompt 3 — Comparativo de produtos

```
Escreva um comparativo em português: "[PRODUTO A] vs [PRODUTO B]: 
Qual Comprar em [ANO]?"

Compare: preço, qualidade, durabilidade, custo-benefício e entrega.
Inclua tabela comparativa.
Indique o melhor para cada perfil de comprador.
CTA para Amazon BR e Mercado Livre nos dois produtos.
Palavra-chave principal no título e nos H2s.
```

---

## Prompt 4 — Listicle de categoria

```
Escreva o artigo "Os 7 Melhores [CATEGORIA] para Comprar em [ANO]".

Para cada produto:
- Nome e descrição curta
- Principal vantagem
- Para quem é ideal
- Link de compra (Amazon BR ou Mercado Livre)

Introdução e conclusão com CTA geral.
SEO: palavra-chave no título, H2s e meta description no final.
```

---

## Prompt 5 — Artigo de problema/solução

```
Escreva um artigo em português com foco em resolver o problema: 
"[PROBLEMA QUE O PRODUTO RESOLVE]".

Estrutura:
- Introdução identificando o problema do leitor
- Por que esse problema acontece
- Como [PRODUTO] resolve
- Review rápido do produto
- Onde comprar (Amazon BR e Mercado Livre)
- Conclusão com urgência de compra

Tom empático e direto. SEO otimizado para busca de problema.
```

---

## Funil de monetização

```
Google → leitor com dúvida
→ artigo responde direto
→ CTA natural no texto
→ clique no link afiliado
→ comissão Amazon / Mercado Livre
```

## Como usar no ArticleGeneratorPGA

1. Escolha o **Tipo de Conteúdo** correspondente ao prompt
2. No campo **Instruções Extras** cole as instruções específicas do prompt
3. Selecione o nicho **🇧🇷 Amazon Brasil** ou **🛒 Mercado Livre**
4. Gere o artigo e publique direto pelo Blogger via aba **📤 Publicar**
